# Практическая работа: Основы работы с Git и GitHub

Интерактивный веб-проект с анимацией котика и просьбой поставить отличную оценку («Поставьте 5, пожалуйста!») при скролле.

## Цель работы
- Освоение базового рабочего процесса (Git Workflow):
  - Инициализация локального репозитория (`git init`);
  - Проверка статуса рабочей директории и индекса (`git status`);
  - Добавление и версионирование файлов (`git add`);
  - Создание атомарных коммитов с понятными сообщениями (`git commit`);
  - Настройка связи с удаленным репозиторием на GitHub (`git remote add origin`);
  - Отправка ветки в удаленный репозиторий (`git push`).

## Стек технологий
- HTML5 (семантическая разметка)
- CSS3 (тёмная тема, анимации, адаптивный дизайн, Flexbox/Grid)
- JavaScript (обработка событий скролла, Intersection Observer, частицы)
- Git & GitHub (контроль версий и хостинг кода)

## Запуск
Просто откройте файл `index.html` в любом современном браузере.
